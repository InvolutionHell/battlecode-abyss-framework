# Native C++ tests of the released bot (bots/abyss), one build per line:
#   <test file> [compile flags ...]
# run.sh compiles each line as
#   $CXX -std=c++20 -O2 $CXXFLAGS <flags> -I bots/abyss tests/native/<test file>
# and runs the binary; a line passes when it exits with 0 and ran at least one check.
#
# A line without flags tests the module as configured in the final build. A -D flag turns on a module that is compiled
# out of the final build (its default is 0 and wrapped in #ifndef), picks one of that module's modes or parameters, or
# selects a test-only trace. Switches that ablation.hpp sets unconditionally (BC_QUEEN_BREATHE, BC_LONGEST_RESERVE,
# BC_HARVEST, BC_QUEEN_BOXGUARD, BC_MAPNET_EVIDENCE, BC_MAPNET_VALUE, BC_QUEEN_GROWFIRST, BC_QUEEN_KEEPAWAY,
# BC_UNIT_SLOT, BC_FORAGE_PATH, BC_OPEN_EXPAND, BC_OPEN_EXPAND_GATE, ...) cannot be changed from the command line, so
# their tests run at the final build's values.
